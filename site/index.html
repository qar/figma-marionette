Why

The canvas, without the meter.

The official Figma MCP server is great for reading designs, but on the Starter plan it allows only 20 tool calls a month — a single screen can take more than that. Marionette moves the write path onto your own machine.

How it works

Three pieces, one string each.

Nothing to start in a terminal. Open the app, keep its window open, and the Figma plugin and your agent find each other.

1

Your agent sends a script

Plain JavaScript against the Figma Plugin API, POSTed to 127.0.0.1:3055/run. Claude Code does this on its own once the skill is installed.

2

Marionette holds the line

The app queues the script and shows it in its window, along with whether the Figma plugin is connected.

3

Figma performs it

The Marionette plugin runs the script inside the file you have open. The return value and any screenshots flow straight back.

AI agent                         Marionette app                  Figma desktop
  curl POST /run?wait=90  ──▶   127.0.0.1:3055   ◀── GET /pull (every 500ms) ──  Marionette plugin
  ◀── result JSON + PNG paths    queue + window   ◀── POST /result ────────────  runs the script

Install

Five minutes, once.

After the first setup, using Marionette is just: open the app, open the plugin in Figma, talk to your agent.

1Get the app

macOS Apple Silicon & Intel · 5 MB Windows experimental Linux headless

Not notarized yet: on first launch macOS refuses it. Open System Settings → Privacy & Security and click Open Anyway — or install from Terminal:

curl -fsSL -o /tmp/Marionette.zip https://github.com/qar/figma-marionette/releases/latest/download/Marionette-macos.zip && ditto -xk /tmp/Marionette.zip /Applications && open -a Marionette

2Import the Figma plugin

In the Marionette window, open Setup and click Show in Finder. Then in Figma desktop:

Plugins → Development → Import plugin from manifest… and pick that manifest.json.

From then on, run Plugins → Development → Marionette and leave its panel open. The app turns green when it connects.

3Connect your agent

Claude Code: click Install skill in the Marionette window — or add the plugin:

/plugin marketplace add qar/figma-marionette
/plugin install figma-marionette

Any other agent: POST the script and read the JSON.

curl -sS --data-binary @script.js 'http://127.0.0.1:3055/run?wait=90'

Scripts

The whole Plugin API, plus a few helpers.

Same shape as the official use_figma: plain JavaScript with top-level await that returns a JSON-serializable value. A failed script changes nothing in the file.

hello-card.js
// Hello card
await figma.loadFontAsync({ family: "Inter", style: "Bold" });
const { AL, T, shot } = helpers;

const card = AL("VERTICAL", {
  itemSpacing: 8, cornerRadius: 16, fill: "#FFFFFF",
  paddingLeft: 16, paddingRight: 16, paddingTop: 16, paddingBottom: 16,
});
card.appendChild(T("Hello", { family: "Inter", style: "Bold", size: 24 }));
figma.currentPage.appendChild(card);

return { id: card.id, preview: await shot(card, 2) };

Safety

Local, and only local.

  • Listens on 127.0.0.1 onlyNothing leaves your machine; there is no account and no cloud service.
  • Web pages can't pull the stringsRequests from browsers are refused, and so are foreign host names — a website you visit cannot drive your Figma.
  • Errors are atomicA script that throws leaves the file untouched; your agent reads the error and tries again.
  • Close the window, cut the stringsQuitting the app stops the bridge. Nothing runs in the background.

FAQ

Does it only work with Claude Code?

No. Claude Code gets a ready-made skill, but any agent or script that can make an HTTP request — Cursor, Codex, your own tooling — can POST to 127.0.0.1:3055/run.

Why does macOS say it can't verify the app?

The app is signed ad hoc, not notarized by Apple yet. Use Open Anyway in Privacy & Security, or the Terminal install line, which doesn't trigger the prompt. The source and the release build pipeline are public.

Does it replace the official Figma MCP?

For anything that touches the canvas, yes. Keep the official MCP for cloud-only features Marionette can't reach: searching team libraries, Code Connect and creating new files.

Which file does it edit?

The file that is open in Figma desktop with the Marionette plugin running. Keep the plugin panel open while your agent works.

What does it cost?

Nothing. Marionette is MIT-licensed and works with any Figma plan that can run development plugins in Figma desktop.
